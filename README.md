# awp_frontend

Frontend für den Aktion-Weihnachtspäckli-Schichtplan.

## Lokal starten

```bash
npm install
npm run dev
```

## Railway

Dieses Verzeichnis ist ein eigenes Git-Repository. In Railway deshalb:

- Service Source: `johncom3/awp_frontend`
- Root Directory: leer lassen bzw. `/`
- Start Command: automatisch über `npm run start`

Die Backend-URL steht in `public/config.js`. Nach dem Backend-Deployment dort die öffentliche Railway-URL des Backends eintragen und erneut pushen.
